# Card payments failing on the secondary CardSwitch site

## Summary

On Thursday 9 April 2026 card authorisations routed through the secondary CardSwitch site in data centre NB2 failed between 07:00 and 09:25. CardSwitch runs active-active, and the secondary site carries about 40% of traffic, so roughly two in five card payments were declined. Payments through the primary site worked normally.

A new mTLS certificate for the Network Gateway connection had been installed on both sites the evening before using RB-002. On the secondary site the new intermediate certificate was not added to the trust bundle, so when the new certificate became active at 07:00 the Network Gateway could not validate the chain.

This is the second certificate-related incident since INC-2025-041. The expiry monitoring built after that incident went live in March 2026, but it only checked the expiry date of the leaf certificate on the primary site, so it did not catch this.

## Root cause

The card network operator moved to a new intermediate certificate authority this year. RB-002, written as a follow-up to INC-2025-041, described installing the leaf certificate but only mentioned the intermediate in a note at the end. The engineer on the primary site followed the note. The engineer on the secondary site did not see it.

There was no automatic check that the full chain was valid on each site, and the monitoring from INC-2025-041 checked only expiry dates on the primary site.

**Cause category:** expired or mis-deployed mTLS certificate between CardSwitch and the Network Gateway (second occurrence, after INC-2025-041).

## Resolution

Traffic was moved to the primary site, the missing intermediate was installed on the secondary site, and traffic was rebalanced after test transactions passed.

## Lessons learned

- The fixes after INC-2025-041 were too narrow. We monitored the one thing that went wrong last time, not the whole certificate setup.
- Doing the same manual task twice, on two sites, is two chances to get it wrong.
- Moving traffic to the healthy site should have happened in minutes, not after 80 minutes.
